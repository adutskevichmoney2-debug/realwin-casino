## Структура

```
index.html      — готовая сборка (открывается в любом браузере)
assemble.py     — сборщик: склеивает src/* и встраивает картинки
src/
  head.html     — <head>, шрифты, favicon
  body.html     — оболочка приложения и прелоадер
  base.css      — тема, компоненты
  pages.css     — страницы, игры, адаптив
  core.js       — состояние, i18n RU/EN, данные игр, роутер
  ui.js         — шапка, сайдбар, модалки, чат
  views.js      — все страницы
  games.js      — движки игр
  boot.js       — инициализация и прелоадер
```

## Сборка

```bash
pip install pillow            # только для сжатия картинок
python3 assemble.py           # соберёт index.html из src/ + tiles/ + banners/
```

Папки `tiles/` (обложки игр, WEBP 330×440) и `banners/` (WEBP 1500px) в репозиторий не включены — готовые изображения уже встроены в `index.html`.
